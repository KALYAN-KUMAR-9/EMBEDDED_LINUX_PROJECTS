The compilation errors occur because your system is missing bison and flex, which are required parser generators used to build the configuration tools (menuconfig) for U-Boot or the Linux kernel.

- sudo apt-get update
- sudo apt-get install bison flex build-essential 
- sudo apt-get install libssl-dev

- sudo apt update && sudo apt install -y libncurses-dev

************************* Busy box compilation ***************************************************

STEP 1: download busybox <https://busybox.net/downloads/>

STEP 2 : Apply default configuration
make ARCH=arm CROSS_COMPILE=arm-linux-gnueabihf- defconfig

STEP 3 : change default settings if you want 
make ARCH=arm CROSS_COMPILE=arm-linux-gnueabihf- menuconfig

STEP 4 : generate the busy box binary and minimal file system 
make ARCH=arm CROSS_COMPILE=arm-linux-gnueabihf- CONFIG_PREFIX=<install_path> install

to know size of RFS: run <du -sh> or list of RFS <du -h> command

To know the type of busybox: cd bin --> run "file busybox" command
To know the busybox binary size: cd bin/ -> run "ls -l busybox" command
