Beagle bone board setup step by step:
===================================
1. Install ubuntu in virtual machine and make sure istall guest additions.
2. make sure all the tools installed by using "sudo apt-get update" command
3. Verify weather minicom is installed or not in ubuntu by using "sudo minicom" command
4. if not installed then use command "sudo apt-get install minicom" to install minocom.
5. connect USB to TTL converter to your PC and connect via virtual machine from "devices" option in virtual machine.
6. If not connected then run commands "1. sudo groupadd vboxusers", "2. sudo usermod -G vboxusers -a $USER" then restart ubuntu.
7. run command on terminal "sudo dmesg | grep tty" to know USB to TTL converter which USB port it is connected.
8. run command on terminal "sudo dmesg". By default "dmesg" command is not run un unprivilized mode so "sudo" is required to use.


9. To Install Gparted application for making partitions of SD card: run command: sudo apt install -y gparted
10 To install dosfstools: run  comamnd in command line: sudo apt update && sudo apt install dosfstools mtools -y
11. Make sure check with by running "dmesg" command in terminal for checking with partition our SD card is present weather it is sda or sdb.
12. select SD card device partition. While doing work i found with name "sdb"
13. Create FAT 16 partition for BOOT and marked with "boot" flag.
14. Create ext3 file system partition for ROOTFS. Once this is completed then apply changes.
15. copy MLO and u-boot.img file to "BOOT" partition. to copy use command ex: "cp MLO-beaglebone-2013.04 /media/kalyan-kumar/BOOT/MLO". MLO file must be "MLO" only then only ROM can identify the MLO file. uEnv.txt to be written into BOOT partition for giving information how to boot kernel. To copy to ROOTFS from kernel folders use command: Actually manay folders need to copy to ROOTFS partition. run comamnd "sudo cp -r * /media/kalyan-kumar/ROOTFS/"

TO know which image flashed on to the EMMC memory default: use command to run in beaglebone hardware after login, lsb_release -a

Load kernel from u-boot commands:
=================================
- Load the linux kernel image to the DDR memory from mmc 0(SD card) interface.
load mmc 0:1 0x82000000 uImage

- Load the dtb image to the DDR memory from mmc 0(SD card) interface.
load mmc 0:1 0x88000000 am335x-boneblack.dtb

- Send bootargs to the linux kernel from u-boot
setenv bootargs console=ttyO0,115200 root=/dev/mmcblk0p2 rw		#root=/dev/mmcblk1p3 rw -->from eMMC ROOTFS  #root=/dev/mmcblk0p2 rw	-->from SD card rootfs

- Boot from memory command
bootm 0x82000000 - 0x88000000		syntax: bootm <kernel image load address> - <DTB load address>

Solution:
========
The build failed because your host system is missing the LZ4 compression utility. The Linux kernel build framework tries to call lz4c to pack your kernel binary into a compressed image file (piggy_data). [1, 2, 3] 
## The Fix
Install the missing LZ4 legacy tools and developer packaging files depending on your Ubuntu version: [3, 4] 

sudo apt update && sudo apt install -y liblz4-tool lz4

## Why This Happened

* lz4c: not found: Older kernel build frameworks explicitly expect the legacy binary tool wrapper name lz4c instead of just modern lz4.
* Installing liblz4-tool creates the symlinks and commands required to satisfy the build system's script dependencies. [2, 5, 6] 

## Resume Your Build
Clear any broken artifact definitions and re-run your compilation command:

make ARCH=arm CROSS_COMPILE=arm-linux-gnueabihf- -j$(nproc)

Once this step runs to completion, your compiled, compressed image will be ready.

Why the LOADADDR Argument is Mandatory:
- LOADADDR=0x82000000: This tells U-Boot exactly where in the BeagleBone Black's physical DDR RAM to unpack and execute the kernel.
- If you do not pass this parameter during compilation, the build will throw a fatal Argument mandatory error and fail.
